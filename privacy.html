Privacy Policy

Terakhir diperbarui: 29 Oktober 2026

Sumbing Weather Timer by UNIX_STEVE dikelola dari Indonesia. Kebijakan ini menjelaskan data yang diproses Bot dan halaman kebijakan yang dihosting oleh GitHub Pages.

1. Information We Process

Data yang diproses meliputi:

  • ID dan nama server Discord.
  • Konfigurasi timer, label cuaca, bahasa, status timer, serta referensi kanal dan pesan status.
  • Data interaksi perintah dan tombol yang diperlukan agar Bot berfungsi.
  • Log operasional yang dapat memuat ID server, nama server, tindakan, dan dalam beberapa kasus ID pengguna.

Bot tidak sengaja menyimpan isi pesan biasa dan tidak merekam percakapan atau suara pengguna.

2. Purpose and Third-Party Services

Data digunakan untuk menjalankan timer, menyimpan pengaturan, mengirim pengumuman, dan mendiagnosis gangguan.

  • Redis: menyimpan pengaturan dan status timer.
  • Google Translate: menerima teks pengumuman yang diubah menjadi suara, termasuk label cuaca khusus yang ditulis admin.
  • Sentry: jika operator mengaktifkannya, laporan error dan informasi diagnostik dapat dikirim ke Sentry.
  • Discord, penyedia hosting, dan GitHub Pages: memproses data sesuai fungsi layanan masing-masing.

Penggunaan layanan pihak ketiga tunduk pada kebijakan privasi masing-masing penyedia. Data tidak dijual atau digunakan untuk iklan.

3. Data Retention and Deletion

Data konfigurasi dan timer khusus server dihapus dari Redis ketika Bot menerima pemberitahuan bahwa Bot dikeluarkan dari server.

Status timer global tidak terikat pada satu server dan dapat tetap tersimpan. Proyek ini tidak menetapkan masa retensi tetap untuk log, cadangan hosting, atau laporan Sentry. Retensinya bergantung pada konfigurasi operator dan penyedia terkait.

4. Your Choices and Data Requests

Untuk berhenti menggunakan Bot, keluarkan Bot dari server.

Untuk meminta akses, koreksi, atau penghapusan data yang dikelola operator, hubungi server support atau akun Discord pengembang. Sertakan ID server bila relevan.

Pemrosesan yang dikendalikan Discord atau penyedia lain harus diminta langsung kepada penyedia tersebut.
